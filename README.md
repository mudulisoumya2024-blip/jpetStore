# JMeter Performance Testing

## Prerequisites
- Java (version supported by your JMeter release)
- Apache JMeter

## Setup
1. Download Apache JMeter from https://jmeter.apache.org/download_jmeter.cgi
2. Extract the downloaded archive.
3. Open the JMeter `bin` directory.
4. Launch the JMeter GUI.

## Execute Test
Open `TestPlan.jmx` in JMeter and configure the required test parameters before running.
